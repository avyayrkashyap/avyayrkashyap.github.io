Paper Folio

Design primitives

Everything defined once and reused across the six pages: index, about, experiments, moodys, gep, now. Tokens come from src/styles/global.css; component rules are copied verbatim from their Astro files, so what renders here is what renders on the site. Flip the theme to see both palettes.

08 — Conventions

Rules the system relies on

Type and layout stay separate

The .t-* classes carry type only. Max-width, grid placement and page margins live with the component, so an element usually carries both, as in class="ab-lead t-lead".

Scoped styles win

Astro's scoped selectors outrank the global primitives, so a page can override one value without fighting the class.

Opacity, not extra ink colors

Two text tokens cover the whole site. Softer text is the same color at 0.85, 0.75, 0.45 or 0.35 rather than a new value.

Every token has a dark twin

Nothing is derived at runtime. The dark block restates all sixteen, which is why theme flips need no color-mix and no JS beyond setting the attribute.

Motion is always guarded

Every animated component ships a prefers-reduced-motion: reduce block, and the scroll-reveal cards resolve to visible rather than hidden.

One breakpoint

768px, used by every page. Hover-dependent behavior is additionally gated on @media (hover: hover) with a touch fallback that leaves the content open.

No spacing tokens yet

Spacing is the one primitive not yet named. Values are consistent on a 4px ladder but written literally at each use site, so a rename means a find and replace.

Dependency-free

No Tailwind, no framer-motion, no UI library. The toggle's spring feel is plain CSS transitions, and the only external assets are two variable fonts plus one icon glyph.
